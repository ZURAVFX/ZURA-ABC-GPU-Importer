Blender 5.1 / Windows 64-bit / Alembic

Alembic to Blender shape keys, faster.

ZURA ABC GPU Importer reads .abc mesh samples directly through a compiled Alembic backend, so large stable-topology caches become editable Blender shape keys without waiting on per-frame cache evaluation.

Download add-on View on GitHub

Built around the Alembic bottleneck.

Alembic is excellent for moving geometry between DCCs, but heavy caches become frustrating when the animation has to become editable Blender data. This add-on targets that step directly.

  • 01Direct .abc sample readsReads samples through the Alembic C++ library rather than Blender's per-frame evaluation path.
  • 02Native shape keysBuilds the result mesh once, then bakes the animation into shape keys.
  • 03Scan firstShows mesh, sample, vertex and face information before you commit to a bake.

Scan, set the range, bake.

The bake is cancelable, reports progress and status, and leaves already baked shape keys intact if you stop it.

  1. Scan the Alembic file

    Confirm the mesh, sample count and topology before baking.

  2. Set the frame range

    Choose the start and end of the animation you want baked.

  3. Bake direct Alembic

    Write the animation into shape keys, with optional CUDA max-delta comparison on supported NVIDIA GPUs.

Install in Blender.

A Windows 64-bit add-on built for Blender 5.1.

  1. Download the ZIP

    ZURA_ABC_GPU_Importer_Blender51_Win64.zip

  2. Install from disk

    In Blender, open Edit, then Preferences, then Add-ons, choose Install from Disk and select the ZIP.

  3. Enable it and open the panel

    Enable Fast Baker Direct ABC GPU, choose an Alembic file and run Scan Alembic.

Download add-on Compatibility / bugs
Before you bake Shape keys need matching vertex topology across samples, so heterogeneous-topology caches are rejected rather than producing unsafe geometry. This is an early public release. The CUDA comparison path is optional, and the direct Alembic reader is the main acceleration path.
